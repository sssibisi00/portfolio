Financial Transactions & Customer Analysis

I used PostgreSQL to clean and analyse customer, card and transaction data. I checked missing values, duplicates, transaction errors, card usage and customer transaction behaviour. I also used joins to connect the three tables.

Project Goal

The goal of this project was to practise SQL using a large financial dataset. I wanted to understand customer information, the cards they use, their transactions and transaction errors.

Data Cleaning

  • Checked for duplicate IDs.
  • Checked for missing values.
  • Created clean versions of the tables so that I did not change the original data.
  • Removed the dollar sign from money columns and changed them to NUMERIC.
  • Checked why merchant_state and ZIP had missing values.
  • Found that online transactions had missing location information and changed the values to ONLINE.
  • Changed NULL values in errors to No Error.

Some Findings

  • There were 2,000 customers.
  • The average customer age was about 45.
  • The average credit score was about 710.
  • Mastercard was the most common card brand.
  • Debit was the most common card type.
  • There were 13,305,915 transactions.
  • The average transaction amount was 42.98.
  • Online transactions had the highest error rate at 2.28%.
  • Debit cards had the highest number of transaction errors.

Creating the Transactions Table 
-- Creating the transactions table
-- Amount is TEXT because the original data has a $ sign

CREATE TABLE transactions_data (
id INTEGER,
date TIMESTAMP,
client_id INTEGER,
card_id INTEGER,
amount TEXT,
use_chip TEXT,
merchant_id BIGINT,
merchant_city TEXT,
merchant_state TEXT,
zip TEXT,
mcc INTEGER,
errors TEXT
);
Checking for Missing Values 
-- Checking missing values in transactions

SELECT COUNT(*) FILTER (WHERE id IS NULL) AS missing_transaction_id,
COUNT(*) FILTER (WHERE date IS NULL) AS missing_date,
COUNT(*) FILTER (WHERE client_id IS NULL) AS missing_customer_id,
COUNT(*) FILTER (WHERE card_id IS NULL) AS missing_card_id,
COUNT(*) FILTER (WHERE amount IS NULL) AS missing_amount,
COUNT(*) FILTER (WHERE merchant_id IS NULL) AS missing_merchant_id,
COUNT(*) FILTER (WHERE merchant_city IS NULL) AS missing_merchant_city,
COUNT(*) FILTER (WHERE merchant_state IS NULL) AS missing_merchant_state,
COUNT(*) FILTER (WHERE mcc IS NULL) AS missing_mcc,
COUNT(*) FILTER (WHERE errors IS NULL) AS missing_errors
FROM transactions_data;

-- Output:
-- Merchant_state had missing values
-- Errors also had many missing values
Creating the Clean Transaction Table 
-- Creating a clean transaction table
-- Removing $ from amount and changing amount to NUMERIC

CREATE TABLE clean_transactions_data AS
SELECT id AS transaction_id,
date,
client_id AS customer_id,
card_id,
REPLACE(amount,'$','')::NUMERIC AS amount,
use_chip,
merchant_id,
merchant_city,
CASE
WHEN use_chip='Online Transaction'
AND merchant_state IS NULL
THEN 'Online / N/A'
ELSE merchant_state
END AS merchant_state,
zip,
mcc,
errors
FROM transactions_data;
Transaction EDA 
-- Checking total transactions, total value
-- and average transaction amount

SELECT COUNT(*) AS total_transactions,
ROUND(SUM(amount),2) AS total_transaction_value,
ROUND(AVG(amount),2) AS average_transaction_amount
FROM clean_transactions_data;

-- Output:
-- Total transactions = 13305915
-- Total transaction value = 571835522.28
-- Average transaction amount = 42.98
Error Rate 
-- Checking error rate by transaction method

SELECT use_chip,
COUNT(*) AS total_transactions,
SUM(CASE
WHEN errors<>'No Error'
THEN 1
ELSE 0
END) AS transactions_with_errors,
ROUND(
100.0 * SUM(
CASE
WHEN errors<>'No Error'
THEN 1
ELSE 0
END
) / COUNT(*),2
) AS error_rate_percentage
FROM clean_transactions_data
GROUP BY use_chip
ORDER BY error_rate_percentage DESC;

-- Output:
-- Online = 2.28%
-- Chip = 1.51%
-- Swipe = 1.49%
Joining All Three Tables 
-- Joining all three tables

SELECT t.transaction_id,
t.date,
t.amount,
u.customer_id,
u.current_age,
u.gender,
u.credit_score,
c.card_brand,
c.card_type,
c.credit_limit
FROM clean_transactions_data t
JOIN clean_cards_data c
ON t.card_id=c.card_id
JOIN clean_users_data u
ON t.customer_id=u.customer_id
LIMIT 20;
Simple CTE 
-- Using a CTE to first count transactions for each customer
-- Then showing the top 10 customers with the most transactions

WITH customer_transactions AS (
SELECT customer_id,
COUNT(*) AS total_transactions
FROM clean_transactions_data
GROUP BY customer_id
)

SELECT customer_id,
total_transactions
FROM customer_transactions
ORDER BY total_transactions DESC
LIMIT 10;

-- Output:
-- Top 10 customers with the highest number of transactions
